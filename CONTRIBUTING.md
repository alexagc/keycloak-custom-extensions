# Contributing to Keycloak Custom Extensions

Thank you for your interest in contributing!

## How to Contribute
1. Open an Issue using the provided templates to discuss proposed changes.
2. Fork the repository and create a branch (`feat/my-new-spi`).
3. Adhere to the architectural standards defined in [AGENTS.md](AGENTS.md).
4. Commit your changes with clear messages (`feat: add webhook event listener`).
5. Open a Pull Request against `main`.
6. Ensure that all GitHub Actions CI checks pass.
